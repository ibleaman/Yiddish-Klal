# Yiddish Klal

Standard Yiddish keyboard layouts for macOS.

## Download

Download the latest installer from [Releases](https://github.com/ibleaman/Yiddish-Klal/releases).

## Installation

1. Open the DMG file
2. Double-click the "Keyboard Layouts" folder to open it in a new window
3. Drag the keyboard bundle into the opened folder
4. Enter your password when prompted
5. Go to System Settings → Keyboard → Input Sources to add the layout

## Layouts

- **Yiddish Klal**: Standard phonetic (QWERTY) Yiddish keyboard layout
- **Yiddish Klal Ligatur**: Version with precomposed Unicode characters *(for specialized use cases)*
